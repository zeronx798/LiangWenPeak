# 第三方素材

## Running Whale Tail

`resources/icons/running-whale-tail.svg` 的几何路径来自
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的
[`RunningWhaleTail.tsx`](https://github.com/deepseek-ai/deepseek-harness/blob/e4aa508e35286641ec8d6d8c0e37e3df654056a9/packages/client/ui-chat/src/client/chat/RunningWhaleTail.tsx)
静态 SVG 回退，固定提交为 `e4aa508e35286641ec8d6d8c0e37e3df654056a9`。
通过 `scripts/generate-icons.ps1 -RefreshSource` 从原始仓库提取 `REST_PATH`，
将 `currentColor` 固定为 `rgb(82, 161, 243)`。ICO 和 PNG 均由该 SVG 生成。
